# Datasets

Due to file size limits, we do not include the raw datasets in this repository. 
To reproduce the experiments, please download the required datasets and place them in this directory.

## 1. Personal Agent Data (LongMemEval)
- **Source**: https://github.com/xiaowu0162/LongMemEval
- **Format**: Please extract the JSON files into `data/personal_agent/`.

## 2. Medical Agent Data (MIRIAD)
- **Source**: https://huggingface.co/datasets/miriad/miriad-4.4M
- **Format**: Please extract the JSON files into `data/medical_agent/`.

## 3. Financial Agent Data (FinQA)
- **Source**: https://huggingface.co/datasets/galileo-ai/ragbench/viewer/finqa
- **Format**: Please extract the JSON files into `data/financial_agent/`.
